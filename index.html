Как купить

1. Оплатите тариф картой или через СБП (в Telegram-боте или по ссылке продавца).
2. Получите лицензионный ключ автоматически в течение нескольких минут.
3. Активируйте ключ: программа → вкладка «Подписка» → вставить ключ → «Активировать».
4. Ключ привязывается к устройству активации.

Публичная оферта

1. Общие положения. Настоящая оферта — публичное предложение Ведмакова Никиты (далее «Продавец») о заключении договора купли-продажи лицензионных ключей к ПО «VedmakovHelp» на изложенных ниже условиях. Оплата товара означает полное и безоговорочное принятие условий оферты.

2. Предмет. Продавец передаёт покупателю право использования ПО «VedmakovHelp» по простой (неисключительной) лицензии путём предоставления лицензионного ключа выбранного тарифа. Права передаются без установки: ключ активируется в программе.

3. Цена и порядок оплаты. Цены указаны в рублях на этой странице. Оплата производится через платёжный сервис RoboKassa (банковские карты, СБП). Моментом оплаты считается поступление денежных средств на счёт Продавца.

4. Порядок передачи. Лицензионный ключ выдаётся автоматически (Telegram-бот VedmakovHelp или страница оплаты) в течение нескольких минут после оплаты. Ключ привязывается к устройству первой активации.

5. Возврат. До активации ключа возврат возможен в полном объёме по обращению покупателя в течение 14 дней с момента оплаты. После активации возврат возможен только при подтверждённом техническом дефекте товара по вине Продавца.

6. Контакты. По всем вопросам: Telegram @vedmakkov, e-mail продавца указан в платёжных документах RoboKassa.

Политика конфиденциальности

Продавец обрабатывает минимум данных, необходимых для выдачи товара: e-mail/ник покупателя и номер оплаты. Данные не передаются третьим лицам, кроме платёжной системы RoboKassa (в объёме, необходимом для проведения платежа). Персональные данные хранятся в соответствии с 152-ФЗ.
